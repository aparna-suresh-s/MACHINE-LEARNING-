STUDENT PERFORMANCE PREDICTION WITH RANDOM FOREST CLASSIFIER

This project uses a Random Forest Classifier to predict student performance (High, Medium, Low) based on several factors.

1.Features
  ●Data Loading and Preprocessing:
  ●Loads student data, including age, gender, study hours, past grades, and absences, using pandas.
  ●Encodes categorical features ('gender' and 'performance') using LabelEncoder.

●Model Training:
  ●Splits the data into training and testing sets.
  ●Trains a Random Forest Classifier model using scikit-learn.
  ●Model Evaluation:
  ●Evaluates model performance using a classification report.

2.Dependencies
  ●pandas
  ●scikit-learn
